# Stage 2 — Candidate Skill Extraction (`nlp_processing`)

## Overview
`nlp_processing` is Stage 2 of the SIH2026 Skill-Gap Analyzer pipeline. It converts Stage 1 document JSON outputs (`sih2026/data/output/<filename>.json`) into compact, deduplicated candidate skill lists (`<filename>_candidates.json`) suitable as input for Stage 3 local-LLM normalization.

It executes a 4-step pipeline:
1. **Page Classifier**: Filters out administrative pages (credits, examination marks, attendance rules) using regex rules, sentence embedding similarity (`sentence-transformers`), or keyword density fallback.
2. **Sentence Filter**: Filters noisy administrative sentences from kept content pages using regex rules or sentence embeddings.
3. **Skill Extractor**: Runs parallel high-recall extraction on each kept sentence via:
   - Taxonomy exact/alias matching against `skill_taxonomy.json`
   - Zero-shot entity recognition (`gliner`)
   - Unsupervised keyword/phrase extraction (`yake`)
4. **Candidate Cleanup**: Normalizes candidates, applies POS filtering (`spacy`), merges taxonomy terms onto canonical names, fuzzy-deduplicates overlapping phrases, and aggregates page occurrences.

---

## Installation & Optional Dependencies

The core pipeline runs out-of-the-box with lightweight fallback logic (rules + keyword density). Optional ML libraries can be installed to unlock higher precision and zero-shot entity extraction.

```bash
# Basic installation (Stage 1 + YAKE fallback)
pip install -e .

# Install Stage 2 optional NLP/ML dependencies
pip install -e ".[nlp]"
```

### Feature Unlock Matrix
| Dependency | Feature Unlocked | Fallback Behavior if Missing |
| :--- | :--- | :--- |
| `yake` | Multi-word keyword phrase extraction | Skips YAKE extraction pass |
| `sentence-transformers` | Semantic embedding page & sentence filtering | Keyword density & pattern rules |
| `spacy` | Accurately splits sentences & filters non-noun phrase candidates | Regex sentence splitting & rule filtering |
| `gliner` | Zero-shot NER extraction for unseen technical skills | Taxonomy matching & YAKE keywords |

## Execution Instructions

### 1. Via Main Pipeline (Automatic Stage 1 -> Stage 2)
When running the main document processor, Stage 2 automatically runs after Stage 1 and outputs `<filename>_candidates.json` alongside `<filename>.json`:

```bash
python -m sih2026.main path/to/document.pdf
```

### 2. Via Standalone CLI Module
To process an existing Stage 1 JSON document directly:

```bash
python -m sih2026.nlp_processing.pipeline path/to/stage1_output.json [optional_output.json]
```

### 3. Programmatic Python API
```python
from sih2026.nlp_processing import run_pipeline

stage1_json = {
    "filename": "syllabus.pdf",
    "pages": [{"page_number": 1, "text": "UNIT I: Python Programming and Machine Learning"}]
}

candidate_output = run_pipeline(stage1_json, verbose=True)
print(candidate_output["candidate_skills"])
```
